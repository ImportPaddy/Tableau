<h1>Tableau</h1>
<p>
  Here is a collection of my Tableau projects completed during the Data Bootcamp with Leep Talent.
</p>

<h2>
  Overview
</h2>
<p>
  During the second week of the bootcamp I learnt how to use Tableau visualisation software. With Tableau I created many different visuals using various datasets. There was a big focus on showing trends and patterns in the data clearly, so that anyone who needs to access this data can clearly see the information being displayed.
</p>

<h2>
  Skills
</h2>
<ul>
  <li>Link a data set to Tableau</li>
  <li>Make decisions on what data is needed for the visualisations</li>
  <li>Select where to have data show and what type of chart to use</li>
  <li>Format visualisations to display the data clearly and effectively</li>
  <li>Collate multiple visuals into a dashboard, neatly organising the data</li>
  <li>Allow for users to interact with the visuals on the dashboard to gain further insights</li>
  <li>Use the created visualisations and dashboard to analyse the data and recognise patterns and trends</li>
</ul>
